Частые вопросы

Сколько яиц платить?

По столбцам: 0 / 1 / 1 / 2 / 2. Яйца можно брать с любых своих птиц.

Когда активировать способности?

Белая — при выкладывании. Коричневая — при действии в этом ряду. Розовая — при указанном действии другого игрока, максимум один раз между твоими ходами. Жёлтая (Oceania) — в конце игры. Способности необязательны.

Когда перебрасывать кормушку?

Когда она пуста, перебрось все пять кубиков. Если при выборе корма все оставшиеся кубики показывают одну и ту же грань (включая случай одного кубика), можно перебросить все пять. Смешанная грань считается отдельной гранью.

Как оплатить птицу?

Косая черта означает один вид корма на выбор, плюс — оба. При выкладывании птицы можно заменить один недостающий корм двумя любыми. При правилах Oceania нектар может заменить обычный корм; не наоборот.

Конец раунда

Выполните соответствующие способности конца раунда (если есть), оцените цель, оставьте по одному кубику на планшете целей, верните остальные, замените три открытые карты и передайте жетон первого игрока. При Oceania неиспользованный нектар сбрасывается.

Как считать цели?

Синяя сторона: по одному очку за каждый подходящий объект, максимум пять. Зелёная сторона: места по количеству объектов; при равенстве разделите очки занятых мест с округлением вниз. Используйте значения на своём планшете целей.

Как закончить игру?

После 4 раундов выполните способности конца игры, затем посчитайте птиц, бонусные карты, цели раундов, яйца, запасённый на птицах корм и подложенные карты. Если есть Oceania, учтите очки нектара. При ничьей сравните остаток неиспользованного корма.
