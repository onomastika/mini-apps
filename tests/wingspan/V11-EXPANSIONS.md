# V11 independent expansion experiment
This branch is separate from the frozen V11 acceptance run. 302 manually mapped printed powers (base-mode 301, including expansion cards; nectar-only card excluded from base). Includes a restricted two-player Oceania mode: starting nectar, dice, wildcard payment, no nectar in generic two-food trade, round cleanup, spent nectar per habitat and endgame majority. Optional upgrades, birdfeeder reset decisions, official full expansion-specific board variants and all card powers are NOT fully simulated. No strategic superiority claim is made from the 24 smoke games. Optional power choices use fixed heuristics. Card conservation and state invariants run every turn. Board yields use the independent simulator's fixed arrays and need printed-board verification before competitive certification.
Rule reference: https://wingspan.rulepop.com/ .
