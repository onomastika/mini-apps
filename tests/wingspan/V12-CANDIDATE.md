# V11 independent expansion experiment
This branch is separate from the frozen V11 acceptance run. 302 manually mapped printed powers (base-mode 301, including expansion cards; nectar-only card excluded from base). Includes a restricted two-player Oceania mode: starting nectar, dice, wildcard payment, no nectar in generic two-food trade, round cleanup, spent nectar per habitat and endgame majority. Optional upgrades, birdfeeder reset decisions, official full expansion-specific board variants and all card powers are NOT fully simulated. No strategic superiority claim is made from the 24 smoke games. Optional power choices use fixed heuristics. Card conservation and state invariants run every turn. Board yields use the independent simulator's fixed arrays and need printed-board verification before competitive certification.
Rule reference: https://wingspan.rulepop.com/ .

V12 fixes generic two-standard-food payment for printed nectar cost; no nectar is awarded for that conversion. V12 opening compares diversified legal setups on common sampled decks, with conservative fallback to V11. The scenario search uses approximate conditional continuation and is not a full imperfect-information solver. Three previously manual brown powers have restricted expected-value projections; optional exchange and shared effects are not fully modeled.

Cycle 1: 144 games, 18 paired seeds per mode; V12 minus V11: base -0.11, base-strong -2.50, Oceania +0.94, Oceania-strong -1.78. No fallbacks. Cycle 2 uses a common first action across scenarios, stricter per-scenario fallback, no decline in immediately playable birds, and exact setup memo. Fresh seed block 20321101. No repeated first-cycle comparison.

Cycle 3 corrects Oceania grassland printed yields to 1/2/2/2/3/4 (the independent simulator already used this array; see https://www.therewillbe.games/articles-boardgame-reviews/8593-wingspan-oceania-expansion-review). Base-mode strategy is unchanged. Targeted new Oceania seed block; base comparison evidence retained. V11 deployed index.html and cards.json verified byte-identical by cycle-2 browser job.
